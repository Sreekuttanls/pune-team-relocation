# Pune Team Relocation Master Dashboard & Strategy Guide

Welcome to the **Pune Team Relocation Project**. This workspace provides complete research, evaluation frameworks, financial calculators, and tracking tools to relocate the team to Pune, secure a quality **3 BHK apartment (< ₹40,000/month)**, and set up a **4-flex desk office space** nearby.

---

## 🎯 Core Requirements & Objectives

- **Residential Target**: Modern, aesthetic 3 BHK apartment with 100% power backup, gated security, and quality amenities.
- **Budget**: **Under ₹40,000 / month** (₹30,000 – ₹40,000 target range).
- **Workspace Target**: **4-Flex / Dedicated Desks** in a Grade-A coworking space with enterprise-grade internet (dual ISP failover), meeting room credits, and 24/7 access.
- **Commute Goal**: Maximum **5 to 15 minutes** travel time between home and office.
